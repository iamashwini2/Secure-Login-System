## SECURE LOGIN SYSTEM
A Secure Web-Based Authentication System Using Flask and SQLite

## The main objectives are:
1.	Develop a secure user registration system.
2.	Implement secure password hashing.
3.	Implement login and logout functionality.
4.	Protect authenticated pages using sessions.
5.	Implement CSRF protection.
6.	Implement rate limiting.
7.	Validate usernames, email addresses and passwords.
8.	Protect database operations against SQL injection.
9.	Implement optional Two-Factor Authentication.
10.	Add HTTP security headers.
11.	Create automated security tests.
12.	Perform security scanning against the application.
13.	Demonstrate practical cybersecurity concepts.

## Technologies Used

Python-	Backend programming
Flask-	Web framework
SQLite-	Database
SQLAlchemy-	Database ORM
HTML-	Web page structure
CSS-	User interface
Jinja2-	HTML templating
Flask-WTF/CSRF-	CSRF protection
Flask-Limiter	-Rate limiting
TOTP-	Two-factor authentication
Pytest	-Automated testing
Git/GitHub-	Version control
